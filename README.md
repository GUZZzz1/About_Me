## 目录结构

```text
docs/
  index.html          # GitHub Pages 完整版入口
  one-page.html       # GitHub Pages 一页版入口
  assets/             # 页面公开素材
resume/
  20260721/           # 2026-07-21 简历归档
    AI方向简历整合预览.html
    AI方向简历一页版.html

```

后续简历或其他公开文档按 `类型/日期` 增加目录，`docs/` 只保留当前需要在线展示的版本。
